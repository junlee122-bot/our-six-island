# 호현지방 · 게임 라운지

일곱 친구가 모여 옷을 갈아입고, 서로 게임 초대장을 보내 체스·고스톱·섯다·텍사스 홀덤·블랙잭을 즐기는 브라우저 라운지입니다. 라운지에는 고스톱·섯다, 카지노에는 체스·홀덤·블랙잭 테이블이 따로 있습니다.

[바로 플레이](https://junlee122-bot.github.io/our-six-island/)

## 친구들과 게임하기

1. 내 고정 아이디로 로그인합니다. 첫 접속은 **첫 로그인 → 개인 활성화 코드 → 새 비밀번호** 순서로 진행하고 개인 복구 코드를 보관합니다. 도원 `dowon` · 강재 `gangjae` · 민서 `minseo` · 승준 `seungjun` · 민재 `minjae` · 재민 `jaemin` · 호현 `hohyeon`. 캐릭터는 계정에 고정되며 각자의 옷과 소품을 바꿀 수 있습니다.
2. **친구 초대 → 새 라운지 열기**로 방을 만들고 링크 또는 10자리 코드를 공유합니다. 친구는 자신의 계정으로 참가합니다. 한 방은 최대 7명이며 계정당 한 자리만 사용할 수 있습니다. 다른 기기에서 같은 계정으로 방에 다시 입장하면 그 기기가 조작 권한을 이어받습니다.
3. **게임 요청**에서 게임·금액·초대할 친구를 고릅니다. 초대받은 친구는 금액을 확인하고 **참가하기 / 다음에**로 응답합니다. 체스는 2명, 고스톱은 3명, 섯다·홀덤·블랙잭은 선택한 2~7명이 수락하면 시작됩니다.
4. 참가자는 캐릭터가 없는 **게임 전용 화면**으로 함께 이동합니다. 로비의 테이블에서 관전할 수도 있습니다. 서로 다른 인원은 서로 다른 게임을 동시에 진행할 수 있습니다.

초대장은 90초 동안 유효합니다. 이미 진행 중인 게임에 참가했거나 다른 초대를 수락해 대기하는 사람은 중복 참가할 수 없습니다. 혼자 연습하는 모드는 없습니다. 게임 중 로비로 돌아가도 참가 상태는 유지되며, **게임 나가기**는 체스 기권 또는 고스톱 무효 종료로 처리됩니다. 다시 플레이할 때도 친구에게 초대를 보내 동의를 받습니다.

## 옷장과 로비

도원에게 **와이드 팬츠·데님 산책·하츠네 미쿠 복장**을 추가했습니다. 옷 탭의 바지/코스튬 필터로 찾을 수 있습니다. 머리 탭에서 기본 단발 또는 춘리에서 참고한 양쪽 만두머리를 고르고, 소품 탭에서 **응원 머리띠(하치마키)**를 조합하세요. 도원의 7가지 의상 모두 단발·만두머리를 지원합니다. 코디 보관·사진 저장·온라인 외형 공유에도 적용되며 예전 코디는 유지됩니다.

- 전신 그림으로 바뀌는 2D 스타일 4개: 기존 의상과 새 기본복·스트리트룩·외출복. 어색한 머리/몸/옷 분리 합성은 사용하지 않습니다.
- 머리색 8개, 모자 4종, 안경 3종, 꽃 머리핀. 기존 스타일에서는 상의 색도 바꿀 수 있습니다. 재민의 작은 꽃무늬 모자와 기존 안경 에셋을 재사용합니다.
- 기존 여섯 친구의 걷기·인사 프레임을 재사용합니다. 새 의상과 호현은 전신 그림에 가벼운 움직임을 적용합니다. 기기의 동작 줄이기 설정을 따릅니다.
- 캐릭터별 코디 보관함(총 28개), 1000×1200 PNG 사진 저장, 자동 저장, 초기화.
- 바닥 클릭/터치 또는 방향키/WASD로 이동하고, 인사·하트 등의 반응과 방 채팅을 나눌 수 있습니다. 효과음은 기본 꺼짐입니다.

## 게임 규칙

홀덤은 **2~7인 노리밋 텍사스 홀덤**입니다. 규칙 기반 AI 딜러 ‘루미’가 개인 카드 2장, 플롭·턴·리버, 쇼다운과 팟 분배를 자동으로 진행합니다. 블라인드는 100/200범입니다. 체크·콜·폴드·레이즈·올인, 최소 레이즈 및 짧은 올인의 재레이즈 제한, 메인/사이드 팟, 동점 분배, 미콜 베팅 반환을 지원합니다. 딜러는 승부에 참가하지 않습니다. 외부 LLM/API를 호출하지 않습니다. 상대의 손패는 쇼다운 전까지 비공개이며 폴드한 패는 끝까지 비공개입니다.

홀덤에서 자리를 떠나면 이후 차례는 체크 가능 시 체크, 그 외에는 폴드합니다. 이미 올인한 참가자는 쇼다운과 정산에 남습니다. 진행 중인 게임으로 다시 돌아가도 퇴장 결정을 취소하지 않습니다.

### 섯다

라운지의 화투 테이블에서 **2~7인 두 장 섯다**를 즐깁니다. 기존 SVG 화투의 1~10월 광/열끗과 띠 두 장씩, 총 20장을 재사용합니다. 내 패 2장만 전달하고 다른 친구의 손패는 승부 때 공개합니다. 관전자는 행동할 수 없으며 다이한 손패는 공개하지 않습니다.

- 모두 같은 바이인(1,000/5,000/10,000/20,000범)으로 시작하고, 첫 기본금은 100범입니다. 두 장을 받은 후 체크·콜·레이즈·하프/팟 금액 선택·올인·다이를 지원합니다. 최대 손실은 바이인, 수수료는 없습니다.
- 족보는 **38광땡 > 13·18광땡 > 장땡~삥땡 > 알리 > 독사 > 구삥 > 장삥 > 장사 > 세륙 > 갑오~망통**입니다. 광땡은 실제 광 카드 조합만 인정합니다.
- 암행어사(4월 열끗+7월 열끗)는 최고 패가 13·18광땡일 때 잡고, 땡잡이(3월 광+7월 열끗)는 최고 패가 1~9땡일 때 잡습니다. 대상이 없으면 각각 1끗/망통입니다. 38광땡과 장땡은 잡지 못합니다.
- 특수 족보는 [한게임 공식 화투 가이드](https://mgostop.hangame.com/guide/combine/04_04_game_mode.html)를 참고했습니다. **멍텅구리 구사**(4월 열끗+9월 열끗)는 최고 9땡 이하, 다른 **구사**는 알리 이하에서 재경기합니다. 제공처마다 세부 규칙은 다릅니다.
- **이 테이블의 재경기 규칙:** 멍텅구리 구사가 땡잡이보다 우선하며 최고 족보 동률도 재경기합니다. 다이하지 않은 친구 모두가 기존 판돈·남은 칩을 유지하고 새 패를 받습니다. 추가 기본금·다이 복귀·재구매는 없고 다음 생존자가 선이 됩니다. 모두 올인했으면 승부까지 자동으로 재분배합니다. 그 외에는 다시 베팅합니다.
- 같은 바이인과 재구매 없는 재경기 덕분에 쇼다운 생존자의 기여액은 항상 같습니다. 사이드 팟 없이 다이한 참가자의 돈까지 승자가 받습니다. 지갑은 승부가 끝난 뒤 미사용 칩과 판돈을 한 번만 정산합니다.
- 게임을 나가면 다음 행동 차례에 자동 다이하며 퇴장을 취소할 수 없습니다. 이미 올인한 사람은 재경기를 포함한 승부와 정산에 남습니다.

### 블랙잭

카지노의 **블랙잭** 테이블에서 친구 2~7명을 초대해 같은 자동 딜러 루미를 상대로 플레이합니다. 플레이어 카드는 공개되고 딜러의 홀카드와 덱은 공개 시점까지 관전자와 손님에게 전달하지 않습니다. 캐릭터 없이 카드·손별 합계·베팅·승패를 보여주는 전용 화면입니다.

6덱, 소프트 17 스탠드(S17), 최초 두 장의 내추럴 3:2, 일반 승리 1:1, 푸시는 반환입니다. 딜러 내추럴을 행동 전에 확인합니다. 히트·스탠드·처음 두 장 더블다운·같은 값의 두 카드 스플릿 1회(최대 2손)를 지원합니다. 스플릿 뒤 더블다운도 가능합니다. 스플릿 A는 한 장씩 받고 종료하며, 스플릿 후 21은 내추럴이 아닙니다. 보험·서렌더는 없습니다.

기본 베팅은 1,000/5,000/10,000/20,000범이며 **최대 4배를 사전 예약**합니다. 초대장에 기본 베팅과 최대 예약금을 함께 표시합니다. 예를 들어 기본 1,000범이면 4,000범을 예약하고, 일반 패배는 1,000범만 잃고 3,000범을 돌려받습니다. 스플릿 후 양쪽 더블을 모두 잃으면 최대 4,000범을 잃습니다. 미사용 예약금과 배당은 한 번만 정산합니다.

게임에서 나가면 남은 각 손은 자동 스탠드하고 정상 정산합니다. 블랙잭의 딜러 수익·손실은 별도 카지노 장부 `houseBalance`에 기록하여 플레이어 지갑과 예약금을 합친 전체 금액을 보존합니다. 딜러의 장부는 음수가 될 수 있으며, 다른 친구가 배당을 대신 부담하지 않습니다. 기존 지갑은 초기화하지 않고 유지합니다.

## 공통 화폐 ‘범’

- 새 고정 계정에 **100,000범**을 한 번 지급합니다. 서버의 계정 지갑으로 모든 방·기기에서 이어집니다. 옷장 초기화·로그아웃·브라우저 데이터 삭제로 재지급하지 않습니다.
- 체스 판돈, 고스톱 최대 손실, 섯다·홀덤 바이인과 블랙잭 기본 베팅은 1,000/5,000/10,000/20,000범 중 선택합니다. 초대장에 금액을 표시하고 동의한 참가자의 잔액에서 시작 시 예약합니다. 블랙잭은 위의 최대 4배 예약을 적용합니다.
- 체스는 승자가 판돈을 얻고 무승부는 반환합니다. 고스톱은 **1점=100범**, 각 패자의 손실은 예약금 한도로 제한하며 무효판은 반환합니다. 홀덤은 남은 칩과 획득한 팟을 정산합니다. 정산 식별자를 저장해 중복 지급을 막습니다.
- 서버가 패를 나누고 차례·베팅·정산을 검증합니다. 상태와 원장을 같은 DB revision으로 확정한 후 각 참가자에게 본인의 공개 가능한 상태만 보냅니다. 요청 영수증과 접속 세대를 기록해 중복 정산과 오래된 기기의 조작을 막습니다.
- 방을 만든 사람이 나가도 남은 친구들은 계속 진행합니다. 연결이 3분 이상 끊긴 참가자는 다음 서버 요청에서 이탈 처리됩니다. 빈 방의 미완료 예약금은 해당 방에 대해서만 정리합니다.

이전 `hohyeon-beom-ledger-v1` 브라우저 원장은 삭제하지 않습니다. 예전 방장별 기록은 서로 겹칠 수 있어 새 서버 지갑에 자동 합산하지 않습니다. 서버 저장 실패 시 정산을 확정하거나 초기 금액을 다시 지급하지 않습니다.

## 체스와 고스톱

체스는 chess.js 1.4.0을 사용합니다. 합법 수, 체크메이트, 캐슬링, 앙파상, 승급, 스테일메이트를 처리하며 3회 반복과 50수는 자동 무승부입니다. 기보, 체스판 뒤집기, 기권을 지원합니다.

고스톱은 **3인 기본 룰**입니다. 손패 7장/바닥 6장, 3점부터 고·스톱, 광·열끗·띠·피, 고도리, 홍단/청단/초단, 쪽/뻑/따닥/쓸, 피박/광박/멍따를 적용합니다. 개인의 마지막 손패에서는 특수 피 빼앗기 보너스를 제외합니다. 국진 술잔은 열끗으로 고정합니다. 흔들기·폭탄·고박·나가리 다음 판 배수는 적용하지 않습니다. 총통은 상대별 5점이며 피박은 1~5피(0피 면제)입니다. 결과를 게임 화폐 ‘범’으로 정산합니다. 구체적인 룰은 게임 안에서도 볼 수 있습니다.

고스톱 전용 화면은 **세 자리의 실제 패 이동**을 보여줍니다. 상대의 손패는 뒷면과 장수로 표시하고, 세 사람의 획득패는 광·열끗·띠·피별로 항상 공개합니다. 확대 버튼으로 모든 획득패를 펼쳐 볼 수 있습니다. 패 내기 → 더미 뒤집기 → 획득패 수거 → 상대 피 가져오기를 승인된 게임 결과에 따라 순서대로 재생합니다. 모션 중에는 패 선택을 잠시 막고, 기기의 동작 줄이기 설정에서는 즉시 결과를 표시합니다. 패 효과음은 버튼으로 켤 수 있습니다.

## 연결과 저장

GitHub Pages는 화면과 에셋을 배포하고, 기존 Supabase 프로젝트의 Auth·Postgres·Edge Functions가 로그인과 저장, 게임 진행을 담당합니다. 별도 VPS를 실행할 필요는 없지만 로그인과 플레이에는 인터넷 연결이 필요합니다. 기존 투표 테이블과 프로젝트의 전역 Auth 설정은 변경하지 않았습니다.

- **자동 저장 / 지금 저장**: 코디, 보관한 의상, 방문 기록을 계정에 저장합니다. 다른 기기의 변경과 충돌하면 서버의 코디를 불러오거나 내 코디로 덮어쓸지 선택합니다. 실패한 코디는 계정별 로컬 임시 기록으로 보관하고 다시 접속할 때 복구할 수 있습니다.
- **내 계정**: 상단 프로필 버튼에서 비밀번호 변경, 저장, 이전 브라우저 코디 가져오기, 로그아웃을 지원합니다. 비밀번호 변경·복구는 새 복구 코드를 발급하고 기존 앱 세션을 폐기합니다. 복구 코드는 개인별로 보관하세요.
- **개인 패**: 전체 덱과 상대 비공개 패는 서버에만 저장합니다. Realtime에는 revision 알림만 보내며, 실제 화면은 인증 API로 받아옵니다. 알림이 늦으면 8초 간격과 딜러 진행 시점의 조회로 복구합니다.
- **방 복귀**: 새로고침 후 친구 초대에서 ‘참가 중인 라운지로 돌아가기’를 누릅니다. 같은 계정은 한 방에만 참가하고 새 연결이 이전 연결의 조작 권한을 승계합니다.

## 개발과 검증

Node.js 22.13 이상에서 `npm ci` 후 `npm run dev`를 실행합니다.

- `npm test`: 규칙, 저장, 초대 경쟁, 카드 보존, 암호화 등 회귀 검사
- `npx tsc --noEmit`: 타입 검사
- `npm run test:lounge-multiplayer`: 보존된 이전 P2P 전송 회귀 테스트. 실제 독립 클라이언트 7명으로 배역 경쟁, 의상, 초대, 동시 게임, 체크메이트, 고스톱·7인 섯다·7인 홀덤·7인 블랙잭 완주, 공통 범 및 카지노 장부 정산, 지갑 재접속, 한글 채팅과 퇴장 검사
- `npm run build:pages`: 프로덕션 빌드 및 에셋 72장을 포함한 단일 `docs/index.html` 생성

GitHub Pages는 main 브랜치의 /docs를 게시합니다. 로그인·저장·게임에는 인터넷과 HTTPS 보안 컨텍스트가 필요합니다. 이전 P2P 클라이언트와는 다른 서버 라운지이므로 친구들도 최신 Pages 주소로 접속해야 합니다.

이미지 프롬프트와 외부 아트 라이선스는 [ASSETS.md](ASSETS.md)에 기록했습니다. 배포 HTML 안에도 외부 소스의 라이선스와 저작권 고지를 포함합니다.
