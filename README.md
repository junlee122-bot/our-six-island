# 우리들의 여섯섬

사진에서 출발한 여섯 친구와 호현 촌장이 함께하는 브라우저 섬 생활 게임입니다. 4800×3200 크기의 섬을 탐험하고, 집과 상점에 들어가 가구를 만들고 텃밭을 가꿉니다. 지도와 실내 배경은 Real-ESRGAN으로 실제 AI 4배 업스케일한 6144×4096 이미지를 사용합니다.

[바로 플레이](https://junlee122-bot.github.io/our-six-island/)

- 이동: 방향키, WASD, 땅 클릭, 모바일 방향 패드
- 상호작용: E 또는 스페이스, 가까운 대상 클릭
- 주머니: B / 섬 수첩: J / 전체 지도: M / 달리기: Shift + 이동
- 채집물은 30초 후 다시 생성됩니다. 중앙 마을, 햇살 과수원, 솔바람 숲, 반짝 호수, 노을 해변을 탐험할 수 있습니다.
- 마을 북쪽 사무소 앞의 호현 촌장에게 말을 걸어 보세요. 다섯 지역을 모두 둘러보면 도토리 100개를 한 번 받을 수 있습니다.
- 기존 저장은 자동으로 새 지도에 옮겨집니다. 친구 부탁, 소지품, 가구, 이름이 유지됩니다.
- 친구 다섯 명의 부탁을 마치고 사과 2개와 물고기 1마리를 모아 소풍 자리로 가세요.
- 진행은 브라우저 localStorage에 저장됩니다. 설정에서 JSON 백업을 내보내거나 불러올 수 있습니다.
- 새로 시작하려면 설정 → **처음부터 시작** → **초기화하고 새로 시작**을 선택하세요. 현재 브라우저의 진행 상황을 지우고 캐릭터 선택으로 돌아갑니다. 확인창에서 취소하면 이어서 플레이할 수 있습니다.
- 음악은 사용자가 켠 뒤 재생되는 Web Audio 합성 멜로디입니다.

## 캐릭터 움직임과 꾸미기

- **C** 또는 오른쪽 **캐릭터 꾸미기** 버튼에서 여섯 친구를 각각 꾸밉니다. 머리색 8개, 옷색 8개, 모자 4종, 안경 3종, 꽃 머리핀을 고를 수 있습니다. 머리 모양과 기본 의상 형태는 각 친구의 특징을 유지합니다.
- 걷기·달리기·인사 미리보기를 보며 고르고 **이 모습으로 저장**을 눌러 적용합니다. 취소하면 변경을 버립니다. **기본 모습**은 선택한 친구만 되돌립니다.
- 걷기는 실제 좌우 발걸음 자세를 번갈아 사용합니다. **Shift**로 달리며, **Q** 또는 손 버튼으로 인사합니다. 채집할 때는 몸을 숙이고, 온라인 이모티콘을 보내면 친구들도 같은 반응을 봅니다.
- 꾸민 모습은 자동 저장·JSON 백업에 포함됩니다. 멀티플레이의 캐릭터와 참가자 목록에도 전달됩니다. 방문자는 방장이 꾸민 NPC들을 보지만 자신의 설정은 유지합니다.
- 나무와 풀은 바람에 흔들리고 바다의 물결, 나비와 갈매기가 움직입니다. 화면 밖의 장식은 그리지 않아 렌더링 비용을 줄입니다. 기기의 **동작 줄이기** 설정에서는 장식 움직임과 모션 미리보기 애니메이션을 줄입니다.

## 새로 열린 섬 생활

아래 메뉴의 **섬 생활**에서 목적지를 골라 걸어가세요. 지도에서는 **바로 이동**으로 지역과 시설에 바로 갈 수 있습니다. 건물 입구에 다가가 **E**를 누르면 안으로 들어갑니다. 실내 작업대에서 다시 E를 누르면 그곳의 기능을 이용하며, 아래쪽 출구나 화면 위 **밖으로** 버튼으로 나옵니다.

- **우리 집:** 주머니의 가구를 선택하고 바닥을 눌러 배치합니다. 가까이 가서 E로 회수합니다. 실내 배치 수를 12 → 20 → 30개로 늘리고, 재료를 수납함에 한 번에 넣거나 꺼낼 수 있습니다.
- **도토리 상점:** 새로 그린 가구 16종과 당근·토마토·호박 씨앗을 삽니다. 가구는 집과 야외에 모두 놓을 수 있습니다.
- **뚝딱 공방:** 나뭇가지·꽃·조개로 가구 16종을 제작합니다. 완성된 가구는 주머니로 들어갑니다.
- **햇살 텃밭:** 밭 6칸에 씨앗을 심고 물을 주면 약 44–77초 뒤 채소 2개를 수확합니다. 모두 물 주기·익은 채소 모두 수확을 지원하고, 게임을 꺼 둔 동안에도 시간이 흐릅니다.
- **노을 카페:** 채소로 요리 3종을 만들어 납품하거나 채소를 그대로 판매합니다.
- **여섯섬 박물관:** 자연물·물고기·곤충 12종을 수집하고 기증합니다. 낚시에서 물고기 4종이 나오며, 섬의 곤충은 가까이 가서 E로 잡습니다. 기증마다 도토리 30개, 전체 완성 시 180개를 받습니다.
- **매일의 선물:** 섬 생활 화면에서 하루 한 번 도토리 40개를 받습니다. 기존 저장에도 새 생활 기능과 시작 씨앗이 자동으로 추가됩니다.

박물관은 수집·기증 수첩과 실내 배경을 제공하며, 전시물의 개별 배치를 바꾸는 기능은 없습니다. 집 단계는 놓을 수 있는 가구 수를 늘립니다.

## 친구와 함께 놀기

캐릭터를 고른 뒤 왼쪽 아래 **친구와 함께 놀기**를 누르세요. **내 섬에 친구 초대하기**로 방을 만들고 초대 링크를 복사해 공유하면 됩니다. 친구는 링크를 열거나 10자리 방 코드를 입력해 참가할 수 있습니다. 최대 6명이 접속하며 같은 캐릭터를 고른 사람도 각자 움직입니다.

- 실외·실내 위치와 걷는 모습, 채팅, 이모티콘이 실시간으로 전달됩니다. 같은 건물 안에 있는 친구끼리 서로 보입니다.
- 방문자는 방장의 야외 가구·집 안 가구·섬 시간을 함께 봅니다. 가구 배치·회수는 방장이 하고, 각자의 소지품·텃밭·기증·부탁·탐험 기록은 개인 진행으로 저장합니다. 공동 텃밭이나 아이템 거래는 지원하지 않습니다.
- **내 섬으로 돌아가기**를 누르거나 방장이 종료하면 방문자는 원래 위치로 돌아갑니다. 초기화와 저장 파일 불러오기도 기존 방 연결을 정리합니다.
- 방장은 게임 탭을 열어 두세요. 멀티플레이는 인터넷 연결과 최신 Chrome·Edge·Safari 등이 필요합니다. 방장이 닫기 버튼으로 종료하면 바로 귀환하며, 브라우저 강제 종료나 네트워크 단절은 최대 약 45초 뒤 반영됩니다.

연결에는 [Supabase Realtime Broadcast](https://supabase.com/docs/guides/realtime/broadcast)를 사용합니다. 연결된 기존 `season-finale-voting` 프로젝트의 게임 전용 `our-six-island-v2:` 채널을 사용하며, 기존 데이터베이스·인증 설정·테이블은 변경하지 않습니다. 클라이언트에는 공개용 publishable key만 포함합니다. 프로젝트가 일시 중지되거나 Realtime 사용 한도에 도달하면 멀티플레이가 제한될 수 있습니다.

방장이 위치·가구·시간을 취합해 최대 초당 4회 전달하고, 화면에서는 이동을 보간합니다. 매 연결마다 생성한 임시 P-256 키로 메시지를 서명하여 발신자와 방장을 검증합니다. 방 코드는 초대받은 친구끼리 공유하세요. 코드로 채널에 참가할 수 있으며 채팅은 종단간 암호화되지 않습니다. 채팅·방 코드·참가자 목록·개인키는 게임 저장 파일이나 데이터베이스에 기록하지 않습니다. 방장 승계와 오프라인 상태의 방 유지는 지원하지 않습니다.

## 개발

Node.js 22에서 `npm ci`, `npm run dev`로 개발 서버를 실행합니다.

게임 규칙 검사: `npm test` · 타입 검사: `npx tsc --noEmit`

실제 통신 검사: Node.js 22에서 `npm run test:multiplayer`. 실제 Supabase 채널에 독립 클라이언트를 연결해 실내외 이동·채팅·이모티콘·집 안과 야외 가구·퇴장·6명 정원·초과 입장 거절을 검사합니다. 테스트는 메모리의 가상 진행만 사용합니다. 브라우저 클릭 자동화나 서로 다른 실제 기기에서의 조작 검사는 포함하지 않습니다.

## GitHub Pages와 다운로드 실행

`npm run build:pages`는 게임 코드, 스타일, 에셋 아홉 장을 모두 포함하는 `docs/index.html`을 만듭니다. GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 게시합니다. 혼자 놀기는 별도 서버나 API 키 없이 실행하며 멀티플레이를 선택할 때만 외부 연결을 시작합니다. 업데이트 후 빌드 결과와 소스를 함께 커밋하고 푸시하면 반영됩니다.

`docs/index.html`을 다운로드한 뒤 브라우저로 열어도 실행할 수 있습니다. 저장 데이터는 브라우저와 주소별로 분리됩니다. 로컬 미리보기에서 GitHub Pages로 옮길 때는 설정의 저장 내보내기/불러오기를 사용하세요.

섬과 캐릭터 일러스트는 OpenAI 이미지 생성으로 제작했습니다. 원본 사진은 배포 파일에 포함되지 않습니다. 도원·강재·민서·승준·민재·재민은 사용자가 제공한 이름입니다. 게임 속 대사와 부탁은 허구이며 실제 성격을 추정하지 않습니다.

새 에셋의 파일 경로, 실제 해상도, AI 업스케일 모델과 라이선스, 이미지 생성 프롬프트는 [ASSETS.md](ASSETS.md)에 기록했습니다.
