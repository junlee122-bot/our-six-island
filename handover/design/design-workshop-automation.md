# 공방 골짜기: 자동화·생산 라인 (스타듀 공방 + 마크/팩토리오 맛) (2026-10-08)

## 1. 왜, 그리고 우리 게임에 맞추는 원칙

스타듀 후반은 옹기·숙성통 수십 개를 돌리는 "공장"이 되고, 마크·팩토리오는 "물건이 알아서 흘러가는 걸 보는 재미"가 핵심이다.
우리 게임에는 이미 재료가 있다: 기계 4종(옹기·숙성통·건조기·씨앗 제조기, `lounge-farm-data.ts:538`), 가공 마당 칸 4→8→12, 시설 부지 틀(`lounge-farm-sites-data.ts`), 광석(구리·철·금·보석)·나무·돌, 우유·달걀·양털, 작물 33종.

지켜야 할 것
1. **돈이 터지면 안 된다.** 하루 판매 상한 10만(`SELL_CAP_PER_DAY`)과 물고기 15만 상한은 그대로다. 공장은 "돈을 더 버는 곳"이 아니라 **마을이 필요로 하는 물건을 만드는 곳**이다. 경제 시뮬레이션(120일 1.07배 이하) 통과가 조건.
2. **서버는 틱을 돌리지 않는다.** 지금 작물처럼 "지난 시간 × 속도"로 읽을 때 계산한다(닫힌 식). 그래서 생산은 **속도(개/게임시간)** 모델이다. 컨베이어를 칸마다 시뮬레이션하지 않는다.
3. **코지 게임이다.** 손으로 하는 길은 그대로 남는다. 공방은 선택이고, 화면은 공장 굴뚝이 아니라 물레방아·풍차·수레 레일이 도는 시골 공방이다.
4. **혼자 해도, 같이 해도.** 내 공방 + 친구들이 함께 쓰는 마을 공장.

## 2. 장소: 공방 골짜기 (새 구역)

- 우리 농장 동쪽 출입문 너머 작은 골짜기. 시냇물이 흐르고(물레방아 자리), 언덕 위는 바람이 분다(풍차 자리).
- **내 공방 터**: 친구마다 격자 12×8칸 → 넓히기 16×10 → 20×12 (농사·솜씨 레벨 + 범·재료).
- **마을 공장**: 가운데 큰 터 24×14, 친구 모두 기계를 놓고 함께 돌린다(마을 개척처럼 기여 기록).
- 시설 부지 틀과 같은 방식으로 저장한다: `workshop[uid] = { size, tiles: {칸: 블록}, store }`, 마을 공장은 `workshop.shared`.

## 4. 계산 방식 (서버 부담 없이)

- 공방 터를 **그래프**로 본다: 들여오기 → (레일·분류) → 기계 → … → 내보내기.
- 놓거나 바꿀 때마다 그래프를 한 번 풀어서 각 줄의 **속도(개/게임시간)**를 정한다: 줄 속도 = min(들어오는 양, 레일 속도, 기계 속도, 동력).
- 읽을 때(하루 마감·접속·창 열기) "지난 시간 × 속도"로 결과를 한꺼번에 계산한다. 재료가 떨어지거나 창고가 차는 시점에서 멈춘다(닫힌 식으로 계산).
- **오래 비우면**: 창고 용량에서 멈춘다. 그래서 "가끔 와서 비워 주는" 리듬이 생긴다(부재 벌은 없음).
- 결정적이고 테스트하기 쉽다. 공방당 블록 상한 300개로 성능을 지킨다.

## 5. 만든 물건은 어디로 (돈 말고)

| 쓰임 | 내용 |
|---|---|
| **마을 주문서** | 주민들이 매주 올리는 대량 주문: "럭스: 빵 40개", "오른: 철 주괴 20개". 보상은 범이 아니라 가구·설계도·칭호·이야기 장(주민 대화 C 시스템의 챕터 조건으로 연결) |
| **마을 공사** | V6~V9(온천·여섯섬 항로·기상 관측소·깊은 굴)의 재료를 주괴·판자·천으로. 공장이 엔드게임을 여는 엔진이 된다 |
| **등대 복원** | 등대 안(새로 만드는 중)의 램프·계단·일지 책장을 공방 물건으로 고쳐 나간다. 엔드게임 "여섯섬의 등대"의 큰 목표 |
| 요리·버프 | 화덕 음식은 하루 버프(걷기 빠름, 낚시 입질 등) |
| 선물 | 포장대 선물 상자 = 주민·친구 선물(내 취향 연결) |
| 판매 | 출하 가능. 가공품은 비싸지만 하루 상한은 그대로라 "같은 상한을 더 적은 손으로 채우는" 효율일 뿐 |

## 7. 화면·조작

- 공방 구역에서 **B키 = 짓기 모드**: 격자, 놓을 블록 미리보기, R로 돌리기, 끌어서 레일 깔기, 우클릭 치우기.
- **흐름 보기(F)**: 레일 위 화살표, 줄마다 "개/게임시간", 막힌 곳 빨갛게. 팩토리오의 "어디가 병목인지 보이는" 재미.
- **설계도 복사·붙이기**: 잘 만든 줄을 저장해서 친구에게 보내기(마을 공장에서 특히).
- 3D: 블록은 인스턴스 모델로 그리고, 레일 위를 작은 상자가 지나가는 것은 **보이는 연출일 뿐**(계산은 4장 방식).
- 소리: 물레방아 물소리, 방앗간 쿵쿵, 풍차 삐걱 (I2-월드에서 넣은 CC0 소리 틀 재사용).

## 8. 같이 하는 재미

- 마을 공장은 친구마다 기계를 놓고 재료를 보탠다. 줄마다 "누가 만든 줄"이 보인다.
- 주간 마을 주문서는 공동 목표 막대(게임 개선안 G12와 합침).
- 친구 공방끼리 **화물 수레**(나중 단계)로 물건을 주고받는다: 내 철 주괴 → 친구 화덕.

## 11. 정할 것 (추천 먼저)

1. **깊이**: 추천은 "스타듀+ 가벼운 팩토리오"(레일·분류·동력까지, 복잡한 논리 회로는 3종만). 대안: 레일 없이 "기계 자동 투입"만(스타듀 수준).
