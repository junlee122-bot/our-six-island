# 연애 대화 확장과 대사 점검 · 2026-11-11

## 목표와 이번 범위

연애가 꽃다발·반지 구매 뒤 호칭만 바뀌는 단계로 끝나지 않도록, 상대가 자기 모습을 조금씩 보여 주고 내 선택을 기억하는 일상 대화를 늘렸다. 기존 인물의 말투·직업·관계·여섯 장 이야기를 유지한다. 신형만과 봉미선은 서로 결혼한 주민이므로 플레이어와의 연애 대상으로 바꾸지 않는다.

이번에는 연애 가능한 주민 27명 전원에게 연인·약혼·결혼 뒤의 선택형 대화를 각 두 편씩, 선택을 기억하는 후일 대화를 두 편씩 넣었다. 총 162편의 단계별 대화와 54편의 기억 대화다. 오프닝·선택지·대답을 합친 새 표시 문장은 2,242개다. 한 문장을 여러 페이지로 나눈 수와 실제 고유 문장 수는 다르므로, 이 숫자를 새 이벤트나 음성 대사 수로 부르지 않는다.

- 추가 위치: `app/npc-talk/<주민 id>.ts`의 `talks`, `callbacks`, `memories`.
- 등록된 주민 29명의 기존 선택형 대화책과 여섯 장 이야기 유지.
- 기존 일상·동행·고백·청혼·배우자 대사는 계속 사용한다.
- 이번 대화는 현재의 연애 단계에서만 열린다. 기혼 주민 둘에게는 새 연애 대화를 넣지 않는다.
- 숫자로 드러나는 호감도, 새로운 과금·아이템 요구, 새 연애 강제는 없다.
- 쉬고 싶다거나 혼자 있고 싶다는 선택을 낮은 등급의 선택으로 만들지 않는다.

## 대화가 달라지는 지점

짧은 칭찬을 여러 직업 비유로 바꾸는 것보다, 같은 인물에게 다른 날 다시 말 걸 이유를 만드는 데 집중했다. 기존 구형 연애 문장에는 인물 사이의 완전한 복사 문장이 거의 없었으므로 단순히 “기존 대사가 전부 복붙”이었다고 평가하면 부정확하다. 실제로 부족했던 곳은 최신 선택형 대화 안의 연애 장면 수였다. 확장 전에는 주민 한 명당 연애 조건이 붙은 선택형 대화가 대체로 영 편에서 네 편이었다.

| 인물군 | 대화에서 다룬 고유한 소재 |
|---|---|
| 미쿠 | 무대 밖의 목소리, 인사를 연습하다 잊는 긴장, 노래하지 않아도 되는 휴식 |
| 예림이 | 상대 표정을 혼자 해석하던 버릇, 소매를 잡기 전 망설임, 기다리다 식은 차 |
| 샹크스 | 허풍 뒤에 감추던 두려움, 출항과 각자의 하루, 귀가 인사 |
| 미스 포츈 | 호의를 부채로 셈하던 버릇, 만나자고 먼저 묻기, 값 붙이지 않는 시간 |
| 나모 | 귀를 만져도 되는지 묻기, 미완성 소설 원고, 돌봄을 정산하지 않는 일상 |
| 그웬 | 웃지 못하는 날의 얼굴, 닮지 않아도 되는 리본 색, 고치지 않고 남겨 둘 흔적 |
| 나세라 | 다 정리하지 못한 말, 함께할 계획의 빈칸, 쉬는 일에 이유를 달지 않기 |
| 프리렌 | 다음이 아니라 오늘 찾아오기, 짧은 시간 앞의 두려움, 평범한 쪽지 |
| 쓰레쉬 | 칭찬을 흥정하지 않기, 비어 있는 추억 선반, 소유하지 않고 듣는 집 안 소리 |
| 나머지 주민 18명 | 각자의 기존 목소리로 데이트·가족/일·서약·귀가·돌봄의 장면을 구성 |

짧은 예시:

> 미쿠: “한 번만 다시 할래. 공연 끝난 뒤의 나로. {me}, 왔어?”
>
> 플레이어: “응, 그 목소리 듣고 싶었어”
>
> 미쿠: “…이상하다. 늘 하던 인산데 더 떨려.”

> 프리렌: “오늘 네 얼굴은 오늘 봐야 하는 거였네.”

> 예림이: “…보고 싶었어. 오늘은 좀 많이.”
>
> 예림이: “이건 늦었다고 나무라는 말이 아니야. 그냥 내 마음이야.”

미쿠의 기존 선택형 대화 두 군데도 바로잡았다. 조용히 있고 싶다는 선택 뒤에도 계속 흥얼거리던 대답은 노래를 쉬는 대답으로, 부끄럽다는 선택 뒤에 굳이 앞에서 부르겠다고 하던 대답은 듣고 싶은 때를 기다리는 대답으로 바꿨다.

## 선택과 기억의 규약

새 대화 id는 `lv-`로 시작한다. 기억은 주민별 관계 행의 기존 `mem`에 저장하고, 기존 최대 스무 개 규약을 그대로 따른다. 새 DB 열이나 새 저장 버전이 필요하지 않다.

- `when.love`로 `dating`, `engaged`, `married`를 구분한다.
- 선택의 `remember`는 실제로 고른 제안이나 대화를 남긴다. 모든 선택을 같은 호의로 재해석하지 않는다.
- 후일 대화는 `when.mem`으로 그 선택을 확인한다. `use`로 해당 기억을 소비해 같은 후일 대화가 매일 반복되지 않게 한다.
- 일반 대화에는 순간적인 날씨·시간 조건을 붙이지 않는다. 특정 순간의 장면을 추가하려면 `openers`에 둔다.
- 기존 챕터의 순서나 이행 조건을 바꾸지 않는다. 이전 저장에서 같은 장면을 다시 완료하게 만들지 않는다.
- 순환·선정 로직의 동작은 `tests/lounge-npc-talk.test.mjs`가 별도로 검사한다.

## 전체 대사 점검 결과와 한계

`node --experimental-strip-types scripts/audit-dialogue.mjs --out <보고서 경로>`로 등록된 정적 대사 데이터를 다시 점검할 수 있다. 서버·계정·지갑에는 연결하지 않는다.

이번 점검 시점의 한글 텍스트 레코드는 48,472개다. 여기에 NPC 선택지·장면 설명·수첩의 기억 설명이 포함되므로 전부 캐릭터의 발화라고 부르면 안 된다.

| 대사군 | 점검한 한글 텍스트 레코드 |
|---|---:|
| NPC 선택형 대화책 | 27,851 |
| NPC 기본 일상 | 7,990 |
| NPC 추가 일상·최근 행동·주민끼리 어울리기 | 2,510 |
| 동행 | 5,044 |
| 연애·결혼·기혼 주민 우정 | 3,445 |
| 주민간 대화 | 588 |
| 연애 관련 주민간 대화 | 452 |
| 생일 | 69 |
| 쉬는 친구 대사 | 371 |
| 게임 진행자·주점·증권 | 152 |

자동 점검 범위:

- 주민별 대화 등록 누락, 중복 대화 id, 기억 생산자와 참조의 연결.
- 새 연애 대화의 단계별 수량, 기혼 주민의 우정 전용 처리.
- 새 대사의 길이, 선택지 길이, 이름표·조사 규칙, 영어·숫자·이모지, 조건의 모순.
- 기존 정적 문장들의 길이와 완전 중복 후보 목록. 유사 의미의 문장은 사람이 읽어 판단해야 한다.

이번 실행에서는 새 확장의 구조 오류와 검토 경고가 없었다. 스무 자 이상인 완전 중복 후보는 142그룹이다. 상당수는 같은 인물의 예전 한 줄 대화와 최신 선택형 대화가 같은 문장을 공유하는 경우다. 이것을 모두 복사 실수로 판정하거나 자동 삭제하지 않는다. 길이 후보 한 개는 샹크스의 기존 챕터 안내문으로, 대사 한 줄의 예순 자 규칙 대신 안내문 여든 자 규칙을 따르는 정상 항목이었다.

기계 점검이 문학적 완성도를 보장하지는 않는다. 인물 설정·말투와 새 장면의 선택 반응을 사람이 검토했고, 명확한 선택 무시 두 군데를 고쳤다. 그러나 48,462개 기존 문장을 모두 같은 깊이로 수동 교정한 것은 아니다. 플레이어가 직접 쓴 한마디, 실행 중 조합되는 모든 UI 문구, 모든 저장 상태에서의 실제 도달성, 실제 화면의 줄바꿈까지 이 스크립트가 보장하지도 않는다.

검증은 `tests/lounge-npc-talk.test.mjs`, `tests/lounge-romance-love.test.mjs`, 새 연애 확장 회귀 검사를 포함한 전체 필수 검사를 기준으로 한다. 배포 상태는 GitHub Actions의 해당 커밋 기록을 확인한다.

## 다음 확장의 우선순위

이번 단계는 관계별 선택과 기억을 넓히는 패치다. 재검수에서 미쿠의 목소리, 예림이가 잡으려다 멈춘 소매, 포츈이 발소리에 고친 옷깃, 나모가 소설보다 오래 보는 얼굴처럼 실제 장면의 거리·시선·작은 행동을 강화했다. 다음에는 이 짧은 만남을 인물마다 고유한 사건으로 연결한다.

1. **인물별 감정 사건**: 캐릭터마다 다른 사건 하나를 세 장면으로 잇는다. 말 한마디가 다음 만남의 태도·소품·회상에 실제로 남게 한다. 같은 갈등을 이름만 바꿔 나누지 않는다.
2. **연애 기억 수첩**: 지금은 소비된 콜백 기억이 일반 기억 제한에 섞인다. 중요한 선택과 함께 본 장면을 별도의 작은 이력으로 보관하고, 플레이어가 원할 때 다시 읽도록 설계한다. 무한 로그 대신 정해진 사건 id를 저장한다.
3. **함께하는 데이트 행동**: 장소만 바뀌는 보상 대신 카페 주문·등대 산책·함께 요리하기처럼 선택과 반응이 이어지는 짧은 행동을 만든다. 성과 경쟁보다 둘의 취향이 드러나는 데 집중한다.
4. **관계의 회복과 다음 날 반응**: 날카로운 대답을 영구적 실패로 만들지 않고, 사과·다른 표현·잠깐 거리 두기로 다시 이야기할 기회를 준다. 무조건적인 칭찬도, 거절을 벌하는 구조도 피한다.
5. **읽는 연출**: 인물별 말 속도·침묵·시선·표정을 장면에 맞게 쓴다. 자동 진행과 효과를 끌 수 있어야 하며, 글과 선택의 개선 뒤에 더한다.

새 NPC나 대규모 장식 그림을 먼저 늘리기보다, 현재 27명 중 몇 명의 관계를 끝까지 살아 있는 경험으로 만드는 순서가 적합하다.
