# NPC 2단계 설계안 (항구 구역 · 언덕 주택가)

작성 2026-09-30 · 상태: 설계안 · 상위 문서: `design-village-2x-npcs.md`

1단계(시장 거리 + 6명)와 같은 규칙을 따릅니다.
- 모든 NPC는 성인이고 연애 가능합니다.
- 그림은 로제·그웬 체형, 한 장짜리 전신 스프라이트(분홍 배경)로 그리고, 대화창 초상은 잘라서 씁니다.
- 일과는 시각으로 계산하고, NPC는 맵 사이를 오갑니다.
- 이름과 생김새는 사용자 레퍼런스로 정합니다. 아래 이름은 **자리 표시**입니다.

## 1. 새 구역 두 곳

| 구역 | 맵 | 여는 조건 | 핵심 장소 |
|---|---|---|---|
| **② 항구 구역** | 60 × 40, 마을 중심 남동쪽 둑길 | 마을 공동 낚시 기부 목표 달성 | 어시장, 낚시조합, 큰 선착장, 등대, 방파제 낚시터 |
| **③ 언덕 주택가** | 50 × 50, 마을 중심 서쪽 계단 | 1단계 NPC 6명 중 3명과 "친한 사이" 달성(이사 이벤트) | NPC 집 8~10채, 도서관, 작은 공원, 할머니 텃밭, 청년 자취방 |

언덕 주택가가 열리면 1단계 NPC들도 **밤에 여기로 퇴근**합니다(그 전에는 마을 중심 가장자리 임시 숙소로 갑니다).

## 2. NPC 8명

| ID(임시) | 역할 | 구역 | 하는 일 | 성격 방향(초안) | 이벤트 |
|---|---|---|---|---|---|
| `fishmonger` | 어시장 상인 겸 낚시조합장 | ② 항구 | 물고기 매입·시세, 희귀 어종 의뢰, 미끼·낚싯대 판매 | 목청 크고 성격 급한 흥정꾼. 새벽 경매 때 제일 신남 | 새벽 경매, **낚시 대회** 주최·심판 |

| `youthA` | 동네 청년 1 (알바생) | ③ 언덕 → 프리렌 빵집 알바 | 심부름 의뢰, 배달 보조 | 부지런하고 눈치 빠름. 프리렌 늦잠 때문에 대신 가게 열쇠를 가짐 | 알바 대타 의뢰, 청년 둘의 내기 |
| `youthB` | 동네 청년 2 (대학생) | ③ 언덕 → 도서관·항구 | 곤충·물고기 채집 의뢰, 숨바꼭질 내기 | 게으른 척하는 천재, 기자 잔나의 제보자 | 채집 대회, 숨바꼭질 내기(친구들 참가) |
| `granny` | 텃밭 할머니 | ③ 언덕(할머니 텃밭) | 텃밭 조언, 제철 요리 레시피, 씨앗 나눔 | 정 많고 잔소리 많음. 나세라의 옛 스승 | 제철 요리 레시피 전수, 김장 행사(겨울) |

## 3. NPC끼리의 관계 (이벤트 재료)

| 관계 | 내용 |
|---|---|
| 어시장 상인 ↔ 잔나 | 잔나 예보가 틀리면 조업을 망쳐서 늘 투덕거림 |
| 등대지기 ↔ 잔나 | 날씨 예보 대결(누가 맞히나 신문에 실림) |
| 사서 ↔ 나세라 | 책 친구, 주 1회 독서 모임 |
| 행상인 ↔ 쓰레쉬 | 희귀품 경매 라이벌 |
| 악사 ↔ 힘멜·프리렌 | 악사는 힘멜의 연애 상담역. 프리렌은 매번 공연 중에 졺 |
| 청년 1(힘멜) ↔ 프리렌 | 알바생과 사장, 힘멜의 짝사랑. 가게 문은 힘멜이 엶 |
| 청년 2 ↔ 잔나 | 제보자와 기자 |
| 할머니 ↔ 나세라 | 옛 스승과 제자 |
| 볼리바스 ↔ 행상인 | 수상한 행상인을 늘 의심함 |
| 신짜장 ↔ 등대지기 | 항구 끝 등대까지 배달이 제일 먼 코스 |

## 4. 구역 이벤트

- **새벽 경매**(항구, 매일 06~07시): 친구들이 잡은 물고기를 비싸게 파는 시간
- **낚시 대회**(항구, 주 1회): 어시장 상인 주최, 등대지기 날씨 발표로 시작
- **장날**(시장, 주 1회): 행상인 방문, 노점, 쓰레쉬와 한정 경매
- **공연 밤**(주점, 주 2회): 악사 공연, 신청곡
- **독서 모임**(도서관, 주 1회): 사서·나세라, 참가하면 연구 보너스
- **김장 행사**(언덕, 겨울): 할머니 주최 협동 요리

## 5. 사용자에게 받을 것 (NPC별)

1단계와 같습니다: 이름, 생김새 레퍼런스(그림 1~3장), 성격·말투 한 줄(없으면 위 초안), 나이대(성인), (선택) 좋아하는 선물. 역할을 바꾸거나 빼도 됩니다.

## 6. 그림 비용

8명 × 1장 ≈ 22크레딧(다시 그리기 포함 약 30크레딧). 현재 잔액 약 73크레딧.

|---|---|
| 레퍼런스 | 사용자 제공: 『리그 오브 레전드』 가렌 초상(2026-09-30). 원본 그림은 저장소에 넣지 않음. 이름 "가붕"(사용자 결정) |
| 생김새 | 남성. 짧은 갈색 머리, 굵은 눈썹, 우렁차게 외치는 얼굴, 은색·금색 큰 어깨 갑옷, 파란 망토. 등대지기답게 손에 큰 등불이나 망원경, 허리에 밧줄 |
| 성격·말투(초안) | 레퍼런스에 맞춰 1장의 "과묵" 초안을 바꿈: 목소리 크고 정의감 넘치는 기사형 등대지기. "이 불빛이 꺼지는 날은 없다!" 같은 외침. 폭풍이 오면 신나서 등대 꼭대기에서 빙글빙글 돎(원작 회전 개그). 잔나 예보보다 자기 감이 맞는다고 우김 |
| 나이대·연애 | 30대 · 연애 가능 |
| 좋아하는 선물(초안) | 든든한 고기 요리, 밤에 잡은 물고기, 광산 금속 |
| 싫어하는 것(초안) | 겁쟁이 같은 말, 꺼진 등불 |

### 힘멜 — 동네 청년 1, 프리렌 빵집 알바생 (`youthA`, 2단계, 일부 초안)

| 항목 | 내용 |
|---|---|
| 레퍼런스 | 사용자 제공: 『장송의 프리렌』 힘멜 공식 설정화(2026-09-30). 원본 그림은 저장소에 넣지 않음 |
| 생김새 | 남성. 파란 단발, 파란 눈, 여유 있는 미소, 남색 제복형 상의·흰 바지·검은 부츠, 크림색 긴 망토. 알바 중에는 망토 위에 빵집 앞치마 |
| 역할 배정 | 청년 두 명 중 **알바생(`youthA`)** 자리. 원작 관계를 살려 프리렌 빵집에서 일함 |
| 성격·말투(초안) | 자칭 "마을의 용사". 잘생긴 척과 폼 잡기를 좋아하지만 누구보다 친절함. 광장에 자기 동상을 세우자고 끈질기게 청원함(원작 동상 개그). 늦잠 자는 프리렌 대신 가게 문을 엶 |

| 좋아하는 선물(초안) | 거울·장신구, 꽃, 프리렌 빵집 신메뉴 |
| 싫어하는 것(초안) | 초라한 옷, 동상 청원 반려 |
