## 돈과 소유권

- 보관금은 `ledger.vault`에 유지하며 판돈·강도 대상으로 쓰지 않는다. 원장 검증의 예약 합계에 포함하고, 파산 구제 판단에서도 자산으로 센다.
- `transferBeom`은 두 계정 사이 이동만, `houseTransfer`는 하우스와 계정 사이 이동만 한다. 대부/상환/환급은 신규 지급으로 집계하지 않는다.
- 친구 차용증: 원금 100~500,000범, 한 번 붙는 이자 0~10%, 수락 후 1~14일. 제안은 24시간 유효. 수락 시 잔액을 다시 확인하고 송금한다. 자동 인출 없이 직접 부분/전액 상환하며 만기 독촉은 차용증당 하루 한 번이다.
- 카지노 대부는 한 사람당 미상환 계약 하나. 대출과 카지노 빚 상환 모두 카지노의 로제 발 위치에서 네트워크 좌표 거리 7.5 이내여야 한다. 서버가 보관한 위치와 접속 상태를 사용하며, 클라이언트가 요청에 넣은 위치는 신뢰하지 않는다. 게임 테이블 참가 중이거나 유효한 낚시가 진행 중이면 거래하지 못한다.
- 원금은 1,000~30,000범, 이자는 `floor(원금 × 0.3)` 한 번, 만기는 계약 시각부터 3일이다. 하루가 지났다고 추가 이자가 붙지 않는다. 상환은 남은 금액 안에서 1범부터 가능하며 자동 인출하지 않는다. 기존 `lender: 'house'` 계약의 ID·원금·이자·만기·기상환액을 그대로 읽는다.
- 은행의 차용증 화면은 로제에게 진 빚의 잔액·만기를 보여 주지만 대출·상환 버튼은 제공하지 않는다. 로제의 별도 장부는 본인 카지노 계약만 표시한다. 친구 차용증의 원격 수락·상환과 기존 은행 보관 동작은 유지한다.
- 강도는 같은 마을에 있고 네트워크 좌표상 6 이내인 접속 친구에게 가능하다. 게임·낚시 중은 보호한다. 시도자와 피해자 각각 하루 한 번, 성공 35%, 실패 시 최대 500범을 상대에게 지급한다.
- 훔칠 수 있는 돈은 소지금 3%/최대 3,000범. 수확물은 일반 품질 한 개. 가구는 두 개 이상 가진 20,000범 이하 일반 판매 가구 한 개이며 명품·기념품·마지막 한 개는 보호한다.
- 방범 자물쇠 1,500범은 24시간, 호루라기 800범은 다음 강도 한 번을 막는다(최대 세 개 보관). 자물쇠가 유효하면 호루라기를 소비하지 않는다.
- 가구 이전 시 양쪽의 해당 가구만 현재 소유량으로 배치를 제한하고 방 revision을 올린다. 과거 프로필 원본을 삭제하지 않는다. [가구 이전 정책](design-furniture-transfer.md) 참고.
- 루미 부탁: 오늘 블랙잭 순손실이 있는 사람이 카지노에서 한국 날짜 기준 하루 한 번, 성공 확률 30%, `floor(오늘 블랙잭 순손실 × 0.5)` 환급. 금액 상한은 없다. 승패 합산 후의 순손실을 사용하며 성공/실패 모두 그날의 부탁을 소진한다. 서버 요청 기록으로 재시도 결과를 고정하고, 10,000범을 넘는 환급도 저장·재접속 시 유지한다. 수익 기록은 생활 업데이트 이후부터다.

## 은행·미용실과 분장실

- 은행·미용실은 마을 건물에서 들어가 바닥을 걷는 장소다. 3D와 간단 화면 모두 같은 장애물·접근 위치를 사용한다. 냐모는 은행 창구 뒤에, 그웬은 미용실 거울 옆에 기존 친구와 같은 2D 전신 스프라이트로 선다.
- 은행은 냐모 앞에서 보관함·친구 차용증을 연다. 카지노의 루미 장부에는 냐모를 표시하지 않는다. 은행 입장·NPC 대화는 이용 경로이며 보관·친구 차용증의 기존 서버 이용 범위를 새로 제한하지 않는다.
- 미용실 거울에서 분장실을 열면 큰 전신 피팅 거울과 의상 서랍이 나온다. 옷/머리/피부/소품/보관함 탭, 도원 바지·만두머리·응원 머리띠, 머리·피부 HEX/RGB 입력, 상점 염색 팔레트, 코디 보관·사진 저장을 유지한다. 변경은 기존 저장 경로를 쓰며 새 서버 기능·저장 형식은 없다.
- 분장실을 마치면 열었던 미용실 또는 내 방으로 돌아간다. Q/E로 분류, 방향키로 선택, 상단 ‘나가기’로 복귀하며 Esc 시스템 메뉴를 유지한다. 계정의 캐릭터 잠금은 바뀌지 않는다.

## 주민 관계

실제 친구 7명의 하트/대사와 별도인 가상 성인 NPC 관계다. 하루 대화 +6, 선물 +8(선호 +12), 친밀도 20부터 내 집 초대, 60부터 초대한 주민과 데이트(+10/하루 한 번), 최대 120. 초대는 20분이며 다시 누르기로 만료 시각을 연장하지 않는다. 선물은 실제 소지품 한 개를 소비한다. 친구에게는 방문한 NPC/만료만 공개하고 개인 점수는 숨긴다.

## 저장·검증·운영

새 금융 상태는 world.finance, 관계·도난 가구 정책은 life.ext에 저장한다. 기존 데이터가 없으면 빈 상태로 시작하며 기존 계정·범·방·가방을 초기화하지 않는다. 로제·냐모·그웬 후속 변경도 기존 금융 계약과 외형 저장을 재사용한다. 프로필/방문/저장 충돌 응답에도 서버 소유량을 적용한다. 게임 저장 테이블은 변경하지 않으며, `hohyeon_economy_vault_report` 마이그레이션으로 관리자 보고서에 보관금을 포함한다. 보고서 함수는 관리자 전용 권한을 유지한다. Edge와 Pages 모두 배포 대상이다.

새 검증 파일: `tests/lounge-finance.test.mjs`, `lounge-life-cloud-integration.test.mjs`, `lounge-furniture-protection.test.mjs`, `lounge-romance.test.mjs`, `lounge-fishing-feedback.test.mjs`, `lounge-village-services.test.mjs`. 실제 계정·비밀번호·서버 저장을 쓰지 않는다. 화면 검증은 `scripts/verify-village-life-ui.mjs`와 `npm run ui:shots`의 로컬 모의 클라우드를 사용한다. CI의 `village-life` 잡은 별도 Linux 환경에서 마을·은행·채집·낚시 조작을 검사하고 보고서와 스크린샷을 보관한다. 이 검사는 네이티브 RAF를 유지하고 날짜만 겨울로 설정한다.

로제 후속 회귀는 `tests/lounge-finance.test.mjs`의 실제 `cloudTransition` 합성 계정 경로로 위치 위조·원격 상환 거절, 같은 요청 재전송, 다른 친구에게 빚 비공개, 이전 계약 재접속·부분/전액 상환, 원장 불변식을 검사한다. `tests/lounge-casino-lender.test.mjs`는 공용 거리·장애물·테이블 보존·이동 경로를 검사한다. `scripts/verify-casino-lender-ui.mjs`는 새 대출/상환 중/연체 화면을 1920×1080·1280×720에서 확인한다. 분장실·은행·미용실의 실제 이동과 저장 재진입은 `verify-village-life-ui.mjs`의 모의 세계를 사용한다. 검사 실행 결과와 배포 완료 여부는 최신 PR 기록을 기준으로 한다.

전체 검사와 배포 결과는 해당 PR의 CI/Pages/Edge Actions 실행 기록으로 확인한다. 새 모델 출처·이용 조건·해시는 `ASSETS.md`와 `public/models/village/life-services/`에 있다. 새 이미지가 필요하면 사용자가 허용한 힉스필드를 사용할 수 있다.
